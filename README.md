User Management API

A simple and efficient REST API for managing users, built with Node.js, Express.js, TypeScript, Prisma ORM, and MongoDB.

Features : 
1. Complete CRUD operations
2. Input validation and error handling
3. Unique email validation
4. Type-safe database queries
5. Node.js & Express.js
6. TypeScript
7. Prisma ORM
8. MongoDB


Configure your environment variables, then initialize Prisma according to your project setup.

Before start the development server:
npm install
npm run dev
